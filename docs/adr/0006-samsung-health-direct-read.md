# ADR-0006: 삼성 헬스 기존 기록은 SDK로 직접 읽고 Health Connect로 보완한다

| 항목 | 값 |
| --- | --- |
| 상태 | 제안 |
| 결정일 | - |
| 결정자 | - |
| 관련 | [S15P31E105-60](https://ssafy.atlassian.net/browse/S15P31E105-60), [ADR-0005](0005-health-connect-mobile-read.md) |

## 맥락

삼성 헬스에 기존 기록이 있어도 HC에 전달된 기록만 읽는 경로에서는 항목이 비어 있었다. 사용자는 새 측정을 기다리는 대신 선택 기간의 기존 기록을 한 번에 조회하도록 요청했다.

## 결정

(가정) Android의 삼성 헬스 지원 항목은 Samsung Health Data SDK 읽기를 우선하고, 성공한 빈 결과·미지원은 HC로 보완한다. 오류·거부는 명시한다. iOS HealthKit은 유지한다. SDK는 개발자 모드로 PoC를 검증하며 공개 배포에는 파트너 등록을 준비한다. ADR0005와 다른 Android 조회 경로를 검증하는 후속 제안으로, 팀 합의 전 기존 ADR 상태를 대체로 바꾸지 않는다.

## 고려한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 삼성 직접 SDK + HC 보완 (제안) | 원천 저장소의 기존 지원 기록 조회 | 삼성 native 모듈·별도 동의·SDK 배포 조건 관리 |
| HC 단독 유지 | 공통 Android 표준/기존 코드 유지 | 삼성의 기존 기록 공유를 강제하지 못함 |
| 사용자가 파일 내보내기/수동 입력 | 과거 자료를 일회 확보할 수 있음 | 자동 조회 요구와 맞지 않고 형식/중복 처리가 필요 |

## 결과

- **얻는 것**: 기존 기록의 일괄 조회와 읽은 저장소 구분.
- **감수하는 것**: 공식 SDK의 지원 항목/버전/권한/파트너 정책에 의존한다. 안정심박·HRV는 확인된 독립 데이터 타입이 없어 HC에 의존하며 추정하지 않는다.
- **후속 작업**: 라이선스 파일 확보·native 호환성·실기기·공개 배포 조건 검증. 팀 합의 전 제안 유지.
