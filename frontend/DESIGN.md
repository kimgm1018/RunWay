# RUNWAY 디자인 기준

앱 화면의 색·박스·작은 컴포넌트 스타일을 정한 문서다(S15P31E105-203). 앱 코드 반영은 S15P31E105-206에서 한다.
화면 구성과 이동 흐름은 프로토타입 v15를 그대로 따르고, 이 문서는 기존 컴포넌트에 입히는 스타일만 정한다. 새 위젯·컴포넌트는 만들지 않는다.
로고·앱 아이콘 규칙은 [CONVENTION.md](CONVENTION.md)의 "로고·앱 아이콘"을 따른다.
앱은 화면 모드를 하나만 쓴다(라이트·다크 전환 없음). 배경은 K1 그라데이션(위는 밝은 청회색, 아래는 검정)이다.

시안 이미지는 저장소 밖 `FE/디자인/`에 있고, 한 장에 한 화면씩 캡처했다.
