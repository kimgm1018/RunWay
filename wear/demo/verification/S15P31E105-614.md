# S15P31E105-614 갤럭시워치·삼성헬스 VO2max 제공 여부 실기기 확인

담당자: 김강민 · 검증 기준일: 2026-11-10

## 목적

러닝 분석에 최대 산소 섭취량(VO2max)을 쓸 수 있는지, Health Services 직접 수집과 Health Connect/삼성헬스 경로를 실기기로 확인한다.

## 변경 범위

워치 데모 RUNNING capability 조회·수집 목록에 `DataType.VO2_MAX`를 추가했다. 지원 여부는 `VO2_MAX.support`로 남기고, 수신 값은 `MetricKind.VO2_MAX` 샘플과 logcat 태그 `RunWayVo2Max`로 확인한다. 측정 상태 화면에 VO2max 지원 문구를 표시한다.

## 실기기 결과 (2026-11-10)

| 항목 | 결과 |
| --- | --- |
| 기기 | Galaxy Watch7 `SM-L300` |
| Wear OS | 16 |
| One UI | `ro.build.version.oneui=80000` (One UI 8) |
| 연결 | 무선 ADB `192.168.30.56:44629` |
| Health Services RUNNING `VO2_MAX` | **unsupported** (`selected=false`) |
| 값 수신 | 없음 (capability 미지원이라 구독하지 않음) |
| 단위 테스트 | `:demo:testDebugUnitTest` — `ExerciseMetadataTest` 통과 |
| 데모 설치 | 서명 불일치로 기존 `com.runway.watchdemo` 제거 후 debug APK 재설치 |

logcat:

```text
I/RunWayVo2Max: capability VO2_MAX=unsupported selected=false
```

사전 조사와 같이 SDK에는 `VO2_MAX` / `VO2_MAX_STATS`가 있으나, 이 기기·One UI 8 조합에서는 RUNNING capability에 포함되지 않았다. 사용자 확인으로 산소 관련 기능은 One UI 9 이상·해당 지원 워치에서만 열리는 것으로 보이며, 현재 최신은 One UI 8이다. 삼성헬스 앱에서도 해당 계정/환경에 최대 산소 섭취량이 제공되지 않아 Health Connect `Vo2MaxRecord` 실측은 진행하지 않았다(읽을 원천 값 없음).

## 활용 경로 권장

1. **워치 Health Services 직접 수집:** 현재 Galaxy Watch7 + One UI 8 기준으로 **미도입**. One UI 9 이상에서 capability를 재확인한다.
2. **Health Connect / 삼성헬스:** 원천 VO2max가 계정에 생길 때만 재검증. 지금은 제공되지 않음.
3. **자체 추정 / 미도입:** MVP에서는 VO2max를 제품 지표로 넣지 않는다. 필요 시 심박·페이스·GPS 기반 자체 추정은 별도 설계 업무로 연다.
