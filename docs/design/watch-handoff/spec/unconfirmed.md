# 확인 필요 · 디자인 잔여 문제

## 확인 필요 (계약·정책 미확인 — 임의로 구현하지 말 것)
- 서비스 저장소·계약 문서(작성자 로컬 경로)를 이 환경에서 열 수 없어 대조하지 못함 → 계약 대조 결과로 보고하지 않음.
- SET_BPM 범위 60–220·1 BPM 단위, 수동 우선 지속·자동 복귀 조건(9.5f 대안).
- 워치↔휴대폰 끊김 중 제어 처리, S08 휴대폰 인계를 워치에서 고를 수 있는지·서버 확인 신호.
- 시작·제어 미확인 판정 시간, 상태 재조회(다시 확인) 계약, 시작 요청 취소 경로.
- 그룹 종료 시 내 측정 자동 중지, 그룹 중 개인 종료 범위, 그룹 중 리듬 직접 조절 가능 여부.
- 위치 없이 시작 조건, 휴대폰 GPS 보완, 추정값 계산 주체.
- 진행 순서 gap 기준(코스 진행도)·갱신 타임스탬프·stale 의미.
- 저장 확인 2분의 기준 시점, 심박 미수신 시 코칭 중단·‘지금 다시 켜기’ 정의.
- 측면 버튼·회전 입력 사용 범위, 실제 최대 글자 크기, 기기·TalkBack·배터리·번인 검증 안 함.
- 화면 숫자는 모두 목업 데이터이며 실제 API 연동 결과가 아님.

## 디자인 변경이 필요한 잔여 문제 (시안에는 미적용)
| 문제 | 현재 | 최소 변경안 |
| --- | --- | --- |
| 192dp·글자 확대 | 원본은 454px 절대 좌표·고정 폭(단계 표시 258px, 3칸 표 300px). 글자만 키운 근사 검사에서 넘침: 227dp·120% 10개, 192dp·100% 3개, 192dp·120% 24개 화면. | 본문 칸을 화면 비율 좌표로, 큰 글자일 때 단계 표시를 세로 목록으로, 큰 숫자에 상한. |
| 심박·케이던스 호 | 기준 범위가 없어 완료율·점수처럼 읽힐 수 있음. 위치·모양은 유지하고 설명만 바로잡음. | 개인 기준 구간 정의 전까지 빈 트랙, 또는 범위 기준을 화면에 표기. |
| 페이스·BPM 눈금 범위 | 눈금 8′00″–4′00″·150–190은 시안 범위. 범위 밖이면 숫자 유지 + 눈금 끔(9.2c)만 적용. | 사용자 목표 기준 가변 눈금. |
| 오른쪽 손잡이와 아이콘 | 제어 손잡이가 있으면 원본 더보기와 같이 오른쪽 시간·케이던스 아이콘이 숨음. 보이는 손잡이 44×88px(22×44dp)로 작음, 터치 96×96 확보. | 아이콘 위치 이동 또는 하단 제어 영역. |
| 그룹 1쪽 표시 | 그룹 1쪽은 개인 운동 현황 보드를 공용 → 그룹 중임을 알리는 표시가 없음. | 운동 현황 위쪽에 작은 ‘그룹’ 라벨. |
| 하단 버튼 좌표 | left 107·top 358·240×96은 227dp 기준·삼성 Tizen 문서를 참고한 값. Wear OS 공통 규칙 아님. | Wear OS EdgeButton·적응형 배치. |
| 대비 | 흐린 값(흰색 45%)·라벨(흰색 62%)은 원본 그대로. 실제 기기 밝기·글꼴에서 대비 확인 안 함. | 기기 확인 후 필요한 곳만 조정. |

## 접근성·입력
TalkBack 읽기 순서: 상태 아이콘 줄 → 가운데 큰 수치(이름·단위 포함) → 보조 수치 → ‘3쪽 중 1쪽’ → 하단 버튼 → 오른쪽 손잡이(‘일시정지’/‘러닝 종료’). 회전 입력: 쪽 이동(코칭 직접 조절에 쓸지는 확인 필요). 시스템 뒤로·스와이프: 러닝 화면에서 앱을 벗어날 뿐 재개·종료하지 않음, 상세·직접 조절은 원래 쪽으로, 종료 확인은 취소.
