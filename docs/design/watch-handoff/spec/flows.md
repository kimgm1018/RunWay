# 페이지 연결 · 상태 전이

## 개인 러닝
대기(9.1) → 시작 요청 중(9.1c) → [1 운동 현황(9.2) ⇄ 2 페이스 코칭(9.5) ⇄ 3 기록 비교(9.6, 비교 기록을 고른 경우만)] → 정지 요청 중(9.3a) → 일시정지됨(9.3) → 종료 확인(9.3b) → 종료 요청 중(9.3d) → 저장 확인(9.4a) → 분석 중(9.4b) → 결과(9.4)

- 비교 기록이 없으면 2쪽(9.2a). 지표 상세(9.2-1~4)는 현황 수치를 눌러 여는 화면(페이지 아님, 뒤로 = 현황).
- 분기: 시작 실패(9.1d) · 시작 확인 안 됨(9.1e) · 재개 요청 중(9.3c) · 제어 실행 미확인(9.3e) · 휴대폰 인계(9.3f) · 저장 미확인(9.4) · 분석 실패(9.4g)

## 그룹 러닝
그룹 대기(9.1) → 출발·내 시작 확인(9.7a) → [1 운동 현황(9.2 공용) ⇄ 2 공동 페이스(9.7) ⇄ 3 진행 순서·간격(9.8)] → 그룹 전체 종료(9.7b: 종료 알림 → 내 측정 중지 → 저장 확인) → 저장 확인 → 결과

- 개인 종료 경로(일시정지 → 종료)는 그룹에서도 유지. 순위 변형: 공동(9.8b) · 지연(9.8c) · 산정 불가(9.8d) · 내 데이터 없음(9.8e)

## 규칙
| 항목 | 규칙 |
| --- | --- |
| 진입 | 기기 실행이 확인되면 1쪽(운동 현황). |
| 복귀 | 재개 확인 → 일시정지 전 마지막 쪽. 상세·직접 조절 → 뒤로 가기로 원래 쪽. |
| 페이지 점 | 원본 모양(위쪽 호의 점) 유지. 개수 = 실제 갈 수 있는 쪽 수(개인 3 또는 2 · 그룹 3). 상세 화면은 점 없음. |
| 강제 전환 | 없음. 예외(전체 화면): 사용자 요청 결과(정지·재개·종료 확정/미확인), 휴대폰 인계 완료, 그룹 전체 종료 알림. 코칭 수신·연결 문제는 보던 쪽을 유지하고 상태 아이콘·문구만. |
| 제어 | 오른쪽 손잡이 ❚❚ 한 번 = 정지 요청. 화면 전체 탭·측면 버튼에 의존하지 않음. 요청 중 손잡이 잠금. |
| 종료 | 일시정지 → 손잡이 ■ → 종료 확인(취소·종료). 뒤로 가기 = 취소, 재개·종료하지 않음. |
| 개인↔그룹 | 그룹 러닝에는 페이스 코칭·기록 비교 쪽이 없음 → 존재하지 않는 쪽으로 이동하지 않음. |
