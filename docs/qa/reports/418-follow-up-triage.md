# 418 QA 후속 분류 (2026-11-07)

로컬 통합 QA(`docs/qa/reports/`) 결과를 **조치·검증 주체**별로 나눈다.  
상세 증거·TC ID는 각 Suite 보고서를 본다. 진행 요약: [00-progress.md](./00-progress.md).

| 구분 | 의미 |
| --- | --- |
| 실기기·실환경 | 에뮬/API만으로는 판정 불가. 갤럭시·워치·삼성헬스·음원 앱 등 실제 환경 재검증 |
| 프론트 개선 | RN/Wear UI·클라이언트 구현·문구·미구현 화면 |
| 백엔드 개선 | API·DB·Route 연동 서버 측 결함 또는 계약/가드 보강 |
| AI 로직 개선 | AI 서비스·코칭/페이스 추론 품질·발행 조건 |

한 항목이 여러 칸에 걸치면 **주 조치 칸**에 두고, 연관은 비고에 적는다.

## 4. AI 로직 개선 필요

이번 418 실행에서 **AI 추론 로직 자체의 확정 불통과는 없음**(이전 AI04 시퀀스·CPU GRU/ODE·그룹 가이드 페이스 API는 별도 통과 이력).

| 우선 | 항목 | 현상 | 제안 | 참고 |
| --- | --- | --- | --- | --- |
| Med | 러닝 중 자동 코칭 발행 경로 | AI `:8000` UP·모델 로드 OK. API-only 세션은 S10 미구독 → `coaching=null`(계약) | “로직 버그”로 단정하지 말 것. **실기기 S10+W07**로 Cue/가이드·level 규칙을 재검증한 뒤, 그때 이상 패턴만 로직 이슈로 승격 | S04-07 |
| Med | 그룹 진행 중 가이드 페이스 | G10 API 구조는 통과. GPS/페이스 표본 없는 API-only라 순위·stale·가이드 품질은 제한 | 실러닝 표본 업로드 후 `groupGuidePace` vs 개인 목표 혼동 여부 재검증 | S06-20·21 |
| Low | Route 추천 품질 | 엔진 ready 실패로 후보·고도 품질 미평가 | ready 복구 후 추천 0건/극단 조건·품질 이슈를 AI/Route 중 어디에 둘지 분리 | S03-01·04 |

→ **지금은 AI 코드 수정 우선순위보다**, 실기기 구독·센서 입력으로 “발행·품질”을 먼저 재는 편이 맞다.
