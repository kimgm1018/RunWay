# ADR-0016: 이미지는 서버 볼륨에 저장한다

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-10-28 |
| 결정자 | 작업 요청자 — [S15P31E105-217](https://ssafy.atlassian.net/browse/S15P31E105-217) |
| 관련 | [F01](../design/api/files.md#f01-이미지-업로드), [ADR-0014](0014-common-api-authentication.md) |

## 맥락

F01 업로드 바이너리 저장 위치가 필요하다. 독립 images 테이블은 없고 DB는 `image_key`만 둔다.

## 결정

이미지 파일은 **애플리케이션 서버 볼륨(파일시스템)** 에 둔다. S3 등은 이번 MVP에서 쓰지 않는다. 업로드 API는 회원 JWT(ADR-0014)로 인증한다.

## 고려한 대안

| 대안 | 판단 |
|---|---|
| 서버 볼륨 (선택) | 구성이 단순하고 217 확정과 맞음 |
| S3 호환 | 인프라·Secret 부담으로 MVP 제외 |

## 결과

- **얻는 것**: F01을 빠르게 구현·검증할 수 있다.
- **감수하는 것**: 다중 인스턴스·백업은 후속(공유 볼륨 또는 오브젝트 스토리지).
- **후속 작업**: 프로필·크루·게시물 `imageId` 연결, 미리보기 URL 서빙.
