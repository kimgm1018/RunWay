## 맥락

러닝 데이터 분석과 AI 추론 결과를 서비스 백엔드에 제공할 AI 서비스가 필요하다. AI 코드와 API 서버를 같은 Python 환경에서 개발해 연동 부담을 줄인다.

## 결정

AI 서비스는 Python으로 개발하고 FastAPI로 추론 API를 제공한다. 소스는 `ai/`에서 관리하며 모델과 학습 프레임워크는 별도로 확정한다.

## 고려한 대안

AI 코드와 API 서버의 개발 언어를 통일하기 위해 Python과 FastAPI를 채택했다.

## 결과

- **얻는 것**: Python AI 코드를 API 서버에서 활용하고 언어 간 이식 부담 감소
- **감수하는 것**: Java·Spring 백엔드와의 API 연동 및 별도 실행 환경 관리 필요
- **후속 작업**: 프로젝트 초기 구성, 모델 선정, 추론 API 계약 및 오류·타임아웃 처리 정의
