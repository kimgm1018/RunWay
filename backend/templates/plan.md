## 5. 완료 조건과 확인 방법

표가 기본이다. 한 행은 사람이 이해할 수 있는 하나의 완료 조건이며, 한 조건에 여러 테스트를
연결할 수 있다. 내부 용어는 의미를 설명한 뒤 병기한다. “정상”, “정확”, “손실 없이”만으로
기대 결과를 대신하지 않고 응답·오류 코드·필드·DB 상태 등 판정에 필요한 정확한 값을 적는다.
정상·경계·실패·권한·재시도·동시성 중 해당 사례를 빠뜨리지 않는다.

| ID | 완료 조건 | 준비할 상황·입력 | 확인할 행동 | 기대 결과 | 확인 방법 |
| --- | --- | --- | --- | --- | --- |
| AC-1 | | | | | <자동 테스트 / 수동 확인 등; 7장의 T/V ID 연결> |

**상세 확인 방법 — 복잡한 항목에만 추가**

<AC ID: 표만으로 재현이 어려운 데이터 예시·실행 순서·실패 주입·관찰 대상·확인 범위와 한계를 설명한다.
예: 동시 요청은 실제 저장 처리가 겹치도록 실행하고 DB 결과를 확인한다. 순차 재요청과 구분한다.
단순한 조건은 표 설명으로 끝내고 각 행을 장문으로 반복하지 않는다.>
