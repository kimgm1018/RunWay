# RunWay 1차 MVP 기능

- 문서 상태: 1차 MVP 기능 기준
- 반영일: 2026-10-23
- 목적: 1차 MVP에서 제공할 기능 범위를 정의하고 후속 요구사항·ERD·API 문서의 기준으로 사용한다.

## 1차 MVP 기능

| 1차 MVP 기능 내용 | 설명 |
| --- | --- |
| 👤 러닝 프로필 및 목표 설정 | 사용자의 러닝 수준, 목표 거리, 목표 완주 시간, 선호 러닝 환경 등을 정하고 개인화된 코스 및 페이스 추천에 활용 |
| 🔋 AI 운동 준비도 분석 | Galaxy Watch로 수집한 수면, 일상 활동량, 심박수, 최근 운동 기록 등을 분석해 현재 운동 준비도를 점수 또는 단계로 시각화 |
| 🗺️ 러닝 코스 추천 | 현재 또는 지정 위치, 목표 거리, 목표 완주 시간·페이스, 러닝 수준, 평소 러닝 정보, 과거 기록 및 선호 환경을 고려해 서비스 공용 코스의 적합도를 평가하고 추천 |
| 🏃 AI 페이스 분석·예측 | 목표 거리와 완주 시간, 과거 러닝 기록, 현재 페이스 및 남은 거리를 분석해 적정 페이스와 구간별 목표 페이스를 계산하고, 향후 페이스 변화와 목표 달성 가능성을 예측 |
| ❤️ 실시간 운동 상태 분석 | 러닝 중 심박수, 페이스, 케이던스 등의 변화를 분석해 운동 부담, 오버페이스, 페이스 저하 및 평소와 다른 운동 패턴을 감지하고 코칭 전략 조정에 활용 |
| 🎵 개인화 BPM 리듬 가이드 | AI가 결정한 목표 페이스를 개인별 보폭과 케이던스 특성에 맞는 BPM으로 변환하고, 실제 페이스와 케이던스 반응에 따라 리듬을 조정해 안내 |
| 📊 러닝 기록 분석 | GPS 기반 러닝 경로, 거리, 시간, 평균 페이스, 심박수, 케이던스 등을 기록하고 구간별 변화와 최초 목표 달성 여부를 분석하며, 러닝 중 과거 기록의 동일 거리 도달 시간과 현재 기록을 실시간 비교 |
| 👥 그룹런 및 AI 그룹 페이스 분석 | 그룹런을 생성하고 참여하며 참가자별 실시간 거리, 페이스, 진행 현황을 공유. 그룹원들의 운동 상태를 분석해 적정 공동 페이스를 계산하고 그룹 페이스 조정 알림 제공 |
| ⌚ Galaxy Watch 연동 | 워치에서 심박수, 케이던스 등 실시간 운동 데이터를 수집하고 러닝 시작·종료 제어, BPM 리듬, 페이스 조정 및 그룹런 관련 알림 제공 |
| 🤝 크루 탐색·그룹런 모집 | 러닝 크루를 탐색하고 가입을 신청하며 그룹런 모집 정보를 등록해 참여자를 모집 |
| 💬 러닝 커뮤니티 | 러닝 정보, 추천 코스, 운동 경험 및 러닝 기록을 공유하고 사용자 간 소통 지원 |

자동 처리·BPM 수동 조절·그룹 종료·연결 장애 동작의 확정 기준은 [자동 처리 요구사항](requirements.md)를 따른다.

계정 공개 여부·비공개 계정 팔로우 승인·기록 공유 정책은 [계정 공개·팔로우 명세](api/users.md)를 따른다. 코스는 이름 없이 조건 필터로 찾고 개인 저장 별명을 사용할 수 있다.
